# Chatbot_sur_La_Loi_de_Travail_Marocaine
Un assistant juridique intelligent dédié au Code du travail marocain. Il permet aux utilisateurs de poser des questions complexes en langage courant. Grâce à un moteur de recherche hybride précis, il extrait  instantanément les articles de loi pertinents, formule une réponse claire, sans erreur, et cite ses sources officielles.
